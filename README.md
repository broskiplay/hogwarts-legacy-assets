# hogwarts-legacy-assets

Тайлы подложки для интерактивной карты [Hogwarts Legacy](https://broskiplay.ru/hogwarts-legacy-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/<карта>/<z>/<x>/<y>.webp` (512×512) и `tiles/<карта>/manifest.json` — список существующих тайлов
- Карты: `world` (Мир, z0–z6), `hogwarts` (Хогвартс, z0–z5), `hogsmeade` (Хогсмид, z0–z5)

Тайлы взяты с [etalongame.com](https://etalongame.com/interactive-maps/hogwarts-legacy/map/world/) как есть (без перекодирования).
